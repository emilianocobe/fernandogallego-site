## Historias: cómo publicarlas

1. Descargar la imagen desde https://fernandogallego.site/kit/.
2. En Instagram: nueva historia → elegir la imagen.
3. *Stickers* → *Enlace* → pegar `https://fernandogallego.site`. Opcional: cambiar el texto del sticker a «COMPRAR PASE».
4. Apoyar el sticker **sobre el recuadro punteado**, que queda tapado.
